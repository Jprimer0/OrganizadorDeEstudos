# Organizador de Pastas e Arquivos em Python

## Sobre o projeto

Este projeto é um programa desenvolvido em Python para automatizar a criação de pastas, subpastas e arquivos de texto.
O objetivo é praticar conceitos de programação e utilizar a biblioteca `os` para interagir com o sistema de arquivos.

## O que o programa faz?

### 1. Menu de controle
Permite escolher se deseja continuar para a próxima etapa, pular uma etapa ou encerrar o programa.

### 2. Criação de pastas principais
Recebe os nomes das pastas informados pelo usuário e tenta criá-las, verificando se já existem.

### 3. Criação de subpastas
Permite definir quantas subpastas serão criadas e organiza essas subpastas dentro das pastas principais.

### 4. Criação de arquivos `.txt`
Recebe os nomes dos arquivos informados pelo usuário e tem como objetivo criá-los dentro das subpastas.

### 5. Criação de arquivos `.md`
Possui uma etapa destinada à criação de arquivos Markdown, úteis para documentação e anotações.

## Tecnologias utilizadas

- Python
- Biblioteca `os`
- Git e GitHub para versionamento do projeto

## Objetivo de aprendizagem

Praticar funções, listas, estruturas de repetição, condicionais, tratamento de exceções, 
manipulação de caminhos e operações com arquivos e diretórios.
